# UI-превью портфолио

Три концепта, чтобы выбрать направление до переноса в код. Контент во всех трёх одинаковый и демонстрационный (проекты, цифры, почта — заглушки), чтобы сравнивать именно UI.

| Файл | Концепт | Суть |
| --- | --- | --- |
| `a-singularity.html` | **Singularity** | Тёмный космос: WebGL-шейдер «жидкой туманности», имя из частиц, которые разлетаются от курсора, голографические карточки с 3D-наклоном |
| `b-kinetic.html` | **Kinetic** | Швейцарский брутализм: огромная вариативная типографика, буквы меняют ширину и вес от курсора, синий Klein, индекс работ с плавающими превью |
| `c-booser-os.html` | **Booser OS** | Портфолио как операционная система: загрузка BIOS, окна, док, терминал с командами, плеер с синтезатором, дизеринг-обои |
| `b-kinetic-v2.html` | **Kinetic II** | Развитие Kinetic: портфолио как живой шрифтовой образец «Specimen No. 02». Имя-струна с осями, пигмент Ива Кляйна на WebGL, зум в «O», перекидное табло, физика букв в финале LOUD. Спецификация — в `docs/kinetic-ii/` |

## Как смотреть

Файлы написаны как страницы-артефакты (без `<!doctype>`/`<head>`, их добавляет хостинг артефактов). Локально их можно открыть прямо в браузере, без сборки. A, B и C — на чистом JS, нужны только Google Fonts. Kinetic II дополнительно грузит с jsDelivr закреплённые версии `lenis@1.1.13` и `matter-js@0.19.0`; без них страница продолжает работать.

## Сайт

Все варианты публикуются на GitHub Pages: https://4booser.github.io/portfolio/

При каждом пуше в `main` workflow `.github/workflows/pages.yml` запускает `node tools/build-site.mjs`. Скрипт оборачивает каждое превью в полноценную HTML-страницу и кладёт её в `_site/<slug>/` вместе с главной страницей `tools/site/index.html`.

Адреса:

- `/kinetic-ii/`
- `/kinetic/`
- `/singularity/`
- `/booser-os/`

Локальная сборка: `node tools/build-site.mjs`, результат в `_site/`.

После выбора варианта переносим его в нормальный проект (компоненты, контент из конфига, реальные проекты).
